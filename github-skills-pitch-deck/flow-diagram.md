## Key Points

### GitHub Skills as Prerequisites
- **Open-Source**: Free and accessible to all team members
- **Self-Paced**: Teams complete exercises on their own timeline before workshops
- **Topic-Aligned**: Exercises chosen to match workshop focus areas
- **Foundation Building**: Ensures all participants have baseline knowledge

### Expert Workshops Build On This Foundation
- **Customized Content**: Tailored to customer's specific stack and environment
- **Deeper Exploration**: Goes beyond basics covered in Skills exercises
- **Real-World Application**: Uses customer's actual scenarios (greenfield/brownfield)
- **Expert Guidance**: Led by service delivery engineers with deep expertise

## Example Skill Topics

Depending on the workshop focus, customers might complete GitHub Skills exercises in:
- Introduction to GitHub
- Code with GitHub Codespaces
- Communicate using Markdown
- GitHub Actions
- Continuous Integration
- Test with GitHub Actions
- Deploy to Azure
- Publish to GitHub Packages
- Secure your repository
- Dependency review
- Secret scanning

## Benefits of This Approach

1. **Consistent Baseline**: All workshop participants arrive with foundational knowledge
2. **Maximize Workshop Value**: Time spent on advanced topics, not basics
3. **Flexible Learning**: Teams learn prerequisites at their own pace
4. **Cost-Effective**: Open-source Skills exercises reduce training costs
5. **Better Outcomes**: Prepared participants gain more from expert workshops

---

**The Result**: A seamless learning experience that transforms teams from GitHub fundamentals to expert-level implementation.
