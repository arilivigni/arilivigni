# GitHub Skills Pitch Deck

This pitch deck introduces GitHub Skills as a foundational learning path for workshop preparation.

## Contents

- **title-slide.md** - Main presentation title slide (Markdown format)
- **title-slide.html** - HTML version for web-based presentations (recommended for quick demos)
- **flow-diagram.md** - Visual representation of the complete learning journey
- **powerpoint-outline.md** - Template for creating PowerPoint/Keynote presentations
- **quick-reference.md** - Presenter guide with slogans, elevator pitches, and Q&A
- **USAGE-GUIDE.md** - Comprehensive guide on how to use all materials effectively

## Purpose

This deck is designed for introducing GitHub Skills exercises as prerequisites for service delivery engineers to deliver expert workshops. The approach ensures customers gain hands-on experience before diving deeper into specialized topics.

## Quick Start

1. **For a quick presentation:** Open `title-slide.html` in your browser (F11 for fullscreen, arrow keys to navigate)
2. **For reference:** Review `quick-reference.md` for talking points and slogans
3. **For PowerPoint:** Follow instructions in `powerpoint-outline.md`
4. **For detailed guidance:** Read `USAGE-GUIDE.md`

## Usage

Use this deck at the beginning of workshops to:
1. Set expectations for the learning journey
2. Explain the value of GitHub Skills as prework
3. Show how Skills exercises connect to expert services workshops
4. Build buy-in for prerequisites before expert workshops
